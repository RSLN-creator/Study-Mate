# 题目规范

**字段与词表的唯一出处是代码**：题型的词表、字段与「服务哪一层」见 `lib/core/rules.ts` 的 `QUESTION_KIND_SHAPES`（数据契约 `schemas/question.schema.json`），题面排版与字段写法见 `<root>/docs/规范/课件内容格式.md`——本规范**不抄第二份字段表**，只管**出什么题、怎么要求、什么算过**。

## 一、四层

深度由节点的 `objective` 决定，**不由课型决定**（课型的作用见第四节）。`objective` 写到哪一层，题就出到哪一层。层是"题"的词汇，**不进页面**。

| 层 | 含义 | 通过标准 |
|----|------|---------|
| **读懂** | 能解释为什么，不只给结论 | 说清因果与前提 |
| **改对** | 改一处并**先预测**结果，再跑起来验证 | 预测与实测一致，或能解释差异 |
| **查错** | 定位真实 bug 的根因 | 说出根因 + 修复 + 预防 |
| **造出** | 从零做出可运行的东西 | 交付物能跑通 + 能解释取舍 |

## 二、四种题型

| 题型 | 服务哪一层 | 判分 | 必备字段 |
|------|-----------|------|---------|
| **客观题** | 读懂 | 页内自动判 | `opts`（≥2 项）、`ans`（下标从 0 起）、`why` |
| **预测验证** | 改对、查错 | 先写下预测，再跑起来对照 | `预测`、`比对` |
| **开放题** | 读懂、查错 | 展开参考答案与判分要点，学生自评 | `answer`、`criteria` |
| **交付物** | 造出 | 可运行证据（测试／断言／期望输出） | `交付物`、`证据` |

**`criteria`（判分要点）是共享字段**：四种题型都能写——`开放题` 必填，其余题型有判分要点就写进它；它不是「这题其实是开放题」的信号，显式写了 `kind` 的题只在**题型专属字段**上判混用（见代码里的 `SHARED_QUESTION_FIELDS`）。

**题面 `q` 是四种题型的共同前提**：上表「必备字段」是各题型**在题面之外**另要的东西——每道题都必须有 `q`，不分题型、也不分写不写 `kind`；字段名写成别的（`stem`）或缺了，题库检查按 `missing-field` 拦下，阅读端也会直接崩。

选题型：**能自动判的优先客观题；要"说清为什么／找根因"的用开放题；要"先预测再验证"的用预测验证；要真做出东西的用交付物。**

判分三轨**全在阅读端**：客观题即时判、主观题学生自评、实操题由 Host 半代跑。**没有任何一轨叫 agent**，三轨都只产生事实与自评，不产生"你会了"的结论。

> **阶段评估已删（ADR-0006）**：不再有跨节点的综合测验，也没有"考考我"那条路——题只服务本节点 `objective` 与它的层。别把综合性测验加回来。

## 三、出题要求

- 贴近生产场景与真实报错，**坚决避免"背诵定义"的「教条主义」**
- 客观题选项尽量等长、同句式（长度泄露答案，检查只 `WARN` 不阻断）
- **只问理解与权衡、不问机械回忆**：对比、因果、预测、取舍、迁移（如"改了这一处会怎样""你项目里哪一处能用上"）。文件名、命令原文、终端输出、报错的行号列号这类东西，要么由 lab 的断言机器验，要么本就没有教学价值；"想不起来"不该成为判定依据
- **开放题必须同时给参考答案与标准**——学生据此自评，缺一不可；答案不唯一时参考答案要给出可接受的替代方案与判断依据，备好常见错误答案，供批改对照
- **预测验证必须让他先写下预测再跑**：没写预测就等于没做这一层；`比对` 写实测是什么、与预测差在哪
- **交付物写成可核验的**（断言／期望输出／清单）；`solutions/` 与任务分开放、做完才对照
- **题量按"学生作答总时长"估，目标 ≤10 分钟**（不设下限也不硬限题数）：实操课与实验课把题量让给练习，概念课可以多问几道；开放题的参考答案要克制，别写成小作文
- 出题前先读节点的 `objective`、学生最近的 misconceptions、目标层级；**开放题必填判分要点，其他题型有判分要点就写进 `criteria`**（学生点开对照时看到的就是它）
- **题面怎么排版不归本规范管**：数学式、换行、围栏、行长这些格式细节以 `<root>/docs/规范/课件内容格式.md` 为准

## 四、三种课型（「课程大纲」的 `kind`）——只管产不产 lab 材料

| `kind` | 是什么 | 产出 |
|--------|--------|------|
| **概念** | 普通课，只讲不落 lab | 课件（讲解 + 轻量练习） |
| **实操** | 普通课，学一点练一点 | 课件 + **自己的小 lab**（当课练习） |
| **实验** | **里程碑验收课**：与普通课同级插在大纲里，验收"学到目前的知识能做出什么" | **实验说明页**（任务书）+ 实操任务（任务本身就是验收） |

**课型不决定题的层级上限**：题出到哪一层看节点 `objective`，把 `kind` 当上限是旧规则，别加回来。深度与课型是两件事。

实验课验收哪些课写在它的 `prerequisites` 里；进度与置位规则见 `record-keeping`。**普通节点没有第三方验收**：推进靠学生自评 + 作答历史 + 机器事实；只有实验课节点走 `evidence-check` 的验收。

## 五、判分要点

- 结论三档：`通过 / 部分通过（列出缺哪条）/ 不通过（列出原因）`，并给"差一步就能过"的具体建议
- **每条结论必须指向一条具体证据**（作答原文、运行结果、交付物）；指不出具体证据按"不通过"处理
- **不得因为"题是我出的"或"学生说懂了"就判过**——说懂了不是证据。证据可信度排序与证据资格见 `evidence-check`

## 六、lab 规范

**载体由总控与学生确定**；本节只管载体定下来后怎么做，讲解角色不碰 lab。交付物的目录布局（任务、答案、`lab/README.md` 各放哪）与各自的维护者见 `<root>/docs/规范/文件归属.md`，别在本规范里另立一套。实验课用同一套要求，另加一份实验说明页——**说明页也是内容格式正文**（语法见 `<root>/docs/规范/课件内容格式.md`），不是 HTML。

不管什么载体，都要做到这五条：**分步引导**（一小步讲解 + 立刻上手，不一次抛完整任务）；**亲手做**（任务留白给学生写，成品只放答案目录，做完才对照）；**可验证**（能自动验的写断言，不能的给自查清单／期望输出）；**即时反馈**（做完立刻能验，不等 agent）；**卡壳先引导**（读错误信息 → 提示 → 线索，不给答案）。教程部分要带结果（其他语言先跑一遍或贴运行结果）；任务写清"要做什么、要点是什么"。

**参考解必须自包含**：学生把答案目录里的文件拷进自己的任务目录后要能直接编译、直接跑——参考解引用的模板、头文件、夹具都得在它自己那份里；要单独入库的模板另存一份进任务目录，并在 `lab/README.md` 写明两者分工。

### 判分入口与跑手（lab 判分契约）

**命令只有一个来源：题库里那道 `kind: 交付物` 的题的「证据」字段**——命令逐字写在那里，只写「程序 + 参数」的裸词（引号、管道、重定向、变量、通配一律不解析；要这些就写成任务目录里的脚本文件，命令只写「解释器 + 脚本」）。**模型与学生都不能自己编一条命令**：没有「证据」不是「现场想一条」，是这道题还没出完。

判分入口的形态**钉死**：任务目录里的判分脚本固定叫 `check.sh`，「证据」里那条命令跑的就是它。它只跑、只如实退出——**不许自己打印「通过／不通过／成功／失败」这类判定字样，也不许自定义退出码语义**（别立一套只有本课知道的码表）；退出码由跑手如实记下，**非零不是失败判决**。

**跑手是唯一入口，只回事实，不做通过判定**：`结局`（`跑完`／`超时`／`取消`／`起不来`）、`退出码`、`信号`、`stdout`／`stderr` 原文、`字节`、`截断`（头尾都留、中间截掉）；字段名以 `lib/lab/runner.ts` 的 `RunFacts` 为准，本规范不另立一套。**通过与否不在这一层**——由你与总控按这些事实做。

**三处布局**（路径与维护者的唯一出处仍是 `<root>/docs/规范/文件归属.md`）：任务目录（留白任务与断言，学生动手的地方）、答案目录（参考解，与任务分开放）、lab 说明（载体与环境依赖、任务表、卡壳顺序）。**任务目录内部允许课程自定义子目录**（如 `作答/`、`探针/`）；这份契约只认这三处。**它们只以摘要出现**（任务目录与说明各给一行，答案目录不列出来；学生按交付物题的「跑一次」跑起来）——消费约定见 `<root>/docs/规范/课件内容格式.md` §5。

**干净态与作答态各跑一次 `check.sh`**：干净态（参考解还在答案目录里、任务留白）预期**跑不过**——非零退出码或断言失败正是留白有效的证据；作答态（学生做完，或把参考解拷进任务目录）预期跑到没有失败。两次都只是事实，判不判过仍按第五节的三档。

**这套形态有可抄的骨架**：`<root>/templates/lab/` 的骨架——判分入口的框架（`check.sh`：读参数、跑断言、只回事实）、任务目录／答案目录／探针的布局、lab 说明、干净态与作答态两个跑法，外加一条「在干净目录里整套重跑」的自检（`自检.sh`）。新造 lab 从它起，**只填题目与断言**；**同一个判分脚本被重写三遍以上就是规格 bug**——那是骨架没跟上，改骨架、报总控，别在课里再抄一份。

## 七、题目位置与锚点

**题目位置**是「课件内容文件」里给题留的位置，由讲解角色写成一行指令（写法见 `<root>/docs/规范/课件内容格式.md` 第 4 节）。**锚点文本是两个文件之间的唯一接头**：你按它出题，「练习题库」用同一串文本作键，渲染器按它把题放进页面——**锚点写错或被改写＝报错，不会静默少一道题**。

- **只有 `::: quiz` 的层级是元信息**（读懂／改对／查错／造出是选深度的词汇，锚点才是文件之间的接头），它不落到页面上；`::: practice` 的层级是给学生看的**徽标**（不是题目位置、不写 `empty_reason`），写 `练习`／`上手做` 这类中文阶段名。
- **`empty_reason` 的归属**：某个锚点这轮不该出题，你就对它交回一行 `empty_reason: <理由>`，由总控打进内容文件——**讲解角色不写它**；**锚点有题却写了 `empty_reason:` 也报错**。
- 每处放几道题按第三节的题量估；位的**数量不预设**、按内容定，但每一处都要有交代（收紧到相邻题，或对该锚点交回 `empty_reason`）。
- **对照由工具完成，没有人手抄**：只能按锚点逐字对，对不上一律报错——别按序号对照，两处序号不一致时会**静默错位**。

## 八、闭卷卷子（考考我 / 学生自己要做闭卷检验）

**什么时候出**：学生说「考考我」，或他读完一个节点想做一次凭记忆的检验。**这不是阶段评估**
（阶段评估已删，ADR-0006）——它不判进度、不写「已学完」、不为任何节点置位，只产一份**这一次的**
成绩。进度仍按 `record-keeping` 那套（普通节点读完即学完）。

**被试必须是人。** 模型不代答、不代背——课件全文在它的上下文里，「合上原文」对它不构成任何约束，
写出来的东西里没有「提取」这个成分。而闭卷这件事的全部价值就在提取（Karpicke & Blunt 2011）。

**形状**：照抄 `<root>/templates/closed-book/`（卷子与判分键两份骨架）。那个 README 写了三条硬规矩，
不在这里重抄；本节只管**出卷与判分的口径**。

### 出卷

- **五个部分的配分不许改**：骨架 20、因果 35、数值 20、迁移 15、元认知 10。这是量具的一部分——
  改了配分，两次的分数就不可比。
- **卷子里要带节拍表**（三个时点 +1 / +7 / +30 天，按目标保持期挑）。**这是检索练习那条唯一落地的
  地方**——一次性施测分不出「没想起来」与「没学会」，重做才是正确用法。三条硬要求一起写进去：
  **答对了也别停**（答对即停的组一周后剩 35%，继续检索的剩约 80%，Karpicke & Roediger 2008）、
  **别在同一天连做几遍**（同日集中 ≈ 没重复）、**重做时仍然闭卷**。
- **但节拍不是排期。** 系统里没有"到期"记录、没有待办、不会提醒——那是仓库的非目标。写清
  「这一节是建议，什么时候做你自己定；没做到不必补做」。**判据：节拍是卷子里的静态文字；
  一旦系统开始算「哪天到期」，就越界了。**
- **因果是主结局**（35 分），所以「用为什么开场」的题至少占一半；只问"是什么"的题归骨架那 20 分。
- **迁移部分必须是真的迁移**：换一组条件、换一台机器、换一个靶面，答案原文里没有现成的。判断题
  「换个场景还用不用得上」不是迁移题。
- **元认知只判具体程度，不判对错**：写「都不太有底」给 0，写「第 5 节 (a)，能背出那条性质但讲不出
  为什么不成立」给满。
- **每道题都要在判分键里写出「答对什么给满 / 答成什么给一半 / 答成什么给 0」**。只写「答对给分」的
  判分键等于没有判分键——那是印象分。

### 3R 管记忆，不管推断——这条边界以前混着说了

背默协议是「读 → 合上原文回忆 → 带缺口重读 → 再回忆」（3R：read–recite–review）。
**2026-11-15 核 McDaniel et al. 2009 原文时发现，我们把它说宽了。**

McDaniel 的摘要原话：3R 让**自由回忆**优于重读与记笔记；但对**多项选择与解决问题题**，
3R 只优于**重读**，**与记笔记打平**。后续研究说得更直：「**testing on its own does not promote
inferential learning** relative to another effective strategy (i.e., note-taking)」。

**所以这条协议的适用边界是：**

| 指标 | 3R 支持吗 | 真正的依据 |
| --- | --- | --- |
| 背默卡 S1（命题召回） | **支持** | McDaniel 2009；Yang 2021（剂量反应） |
| 卷子「一、骨架」20 分 | 支持（也是记忆类） | 同上 |
| 卷子「二、因果」35 分 | **不支持** | Pan & Rickard 2018（应用/推断题迁移最强） |
| 卷子「四、迁移」15 分 | **不支持** | 同上 |

**不许拿 3R 去给因果与迁移两部分背书。** 它们能成立靠的是迁移研究，不是背默研究。

这正是「引了真的、但用到了它管不着的地方」——比引错更隐蔽。

### 题型有代价：开放式作答的效应量本来就比多选题小

Adesope et al. 2017（元分析，272 个效应）里**练习测试的格式是显著调节变量**：

| 练习测试的格式 | 效应量 g |
| --- | --- |
| 多项选择 | **0.70** |
| 自由回忆 | 0.62 |
| 有提示回忆 | 0.58 |
| **简答 / 开放式** | **0.48** |
| 混合格式 | 0.80 |

**我们的卷子是开放式作答，落在 g≈0.48 那一档——比多选题低一截。**
这不是卷子不好，是题型的固有代价：**多选题好判、好拿分，但练出来的东西也更浅。**

**所以不要在报分时拿"检索练习 g=0.6"去暗示这套卷子的收益**。要写就写清：
- 开放式作答的练习效应约 **g=0.48**；
- **换来的是「能自己写出来」而不是「能认出来」**——而后者在真实场景里没人给选项。

**另一个必须一起报的限定**：常被引用的 **g=0.61** 是 Adesope 的**固定效应模型**估计，
而该研究 **I²=.81**（异质性极高）。同一个研究里 **vs 重读只有 g=0.51**，g=0.93 那个数是
「vs 无活动/填充活动」比出来的。**引 0.61 而不说这两句，就是把一个偏乐观的估计当成了真值。**

### 节拍：什么时候再练一次（B0 / B2 / B3 / B8）

卷子那一节讲的是「同一份卷子隔多久重做」。这里讲的是**平时练题**的节拍——两者不冲突，
但**都要落在产物里**，不能只在设计文档里。

| 拍 | 什么时候 | 练什么 | 证据 |
| --- | --- | --- | --- |
| **B0** | 节点刚读完 | 2 题（1 事实 + 1 变式），**不计分** | Roediger & Karpicke 2006 |
| **B2** | **次日**（T0 + 1 天，窗口 18–36 小时） | 2 题，覆盖**不同子点** | **Cepeda 2008：保持期 7 天时最优间隔是 1 天** |
| **B3** | **一周后**（T0 + 7 天） | 1 道**迁移题** | Cepeda 2008（70 天保持期最优 21 天）；Pan & Rickard 2018 |
| **B8** | 退场判据 | **累计 3 次跨日成功检索**才停 | **Yang 2021：1 次 g=0.444 → 2 次 0.601 → 3 次以上 0.642 → 无限次 0.762** |

**B8 那条要按 Yang 的原数说全**：不是「三次就够」，是**继续做还在涨**（0.642 → 0.762）。
「答对就出队」之所以错，也因为它是把 0.642 那一档当成终点。

**这四拍是静态建议，不是调度器。** 系统里没有「到期」字段、没有待办列表、不会来提醒——
这和卷子那一节同一条边界（`docs/设计/目标态规格.md` §12 把间隔重复列为非目标）。

### 两个证据站不住的拍：B5 与 B6（**先不要做**）

设计文档里还有两拍，**它们的证据自相矛盾或只有单一来源，所以没有落进这一节**：

| 拍 | 设计文档里写的 | 为什么没落 |
| --- | --- | --- |
| **B5 会话组装** | 同一会话里多道同类题时把它们打散，使相邻两题来自不同节点 | 证据是 Taylor & Rohrer 2010（d=1.21）与 Rohrer 2020（RCT d=0.83），**但 Brunmair & Richter 2019 的元分析说"说明性文本交错不显著"**——我们的课件正好是说明性文本。**两条证据方向相反，且都没自己核过。** |
| **B6 反馈** | 延迟到整轮结束再给答案，而不是每题立刻给 | **三方不一致**：Butler 2007 支持延迟、Adesope 2017 说反馈不显著、Yang 2021 说显著。**三个结论互相打架，谁也没核过原文。** |

**没核过、且互相打架的证据不许写成规则。** 这两拍留在设计文档里当"待定"，等核完再落。

### 两份必须分开、必须同时写

**卷子与判分键是两个文件，判分键的名字里要有「判分键」，两份同时落盘。** **两份都只放 `assessments/`——绝不能放进 `reference/` 或任何阅读端能读到的目录**：那是泄题，而且泄得悄无声息（学生打开「参考资料」就看见答案了）。`assessments/` 阅读端不认识，这是判分键唯一的防线。 先出卷、事后补键，键就会
照着学生的答案写——那是自证。**评分的人（无论是谁）必须在评分记录里写一句「我是在收到答卷之后才
打开判分键的」**；这是唯一能让人看出评分有没有被污染的办法。

### 判分

- **只看写出来的内容判，不看答题者什么时候记住的、也不看他的自评。** 2026-11-15 那次两个评分者
  在这一点上分岔：一个把「这一步是回看后才记住的」算进判定，另一个只看产物——同一份答卷判出两个
  结果。那不是评分者误差，是两条判据不一样，所以这里写死。
- **答错不额外扣分**：空着与答错同分。测的是「记住了多少」，不是「敢不敢猜」。
- **数值差在 ±2% 内算命中**（计算器与四舍五入的差别不该扣分）；量纲不自洽按没答上。

### 三条判定带，但**单次施测分辨不出它们**

按 20 个计分点算，题目 bootstrap 的半宽是 **6–19 分**（实算；复现入口见测试说明里
`test_closed_book_template` 那一行）。总分只有 100，要把三条带
分到互不重叠得隔 30 分以上——**做不到**。所以：

- **三条带是报告用语，不是判决。** 报的时候写「本次落在『部分通过』一带」，不写「没通过」。
- **不许拿一次分数下结论。** 要谈变化，必须同一份卷子隔一段时间重做、看两次是否落在同一带，
  或者换一份平行卷。单次施测能回答的是「哪一部分最弱」——**剖面比总分稳得多**。
- **分数差在半宽之内（最坏 19 分）一律视为波动**，不报成「进步」或「退步」。**按最坏情形报，
  不按那次答卷自己算出来的小半宽报**——否则「几乎全对」那一档半宽只有 6 分，会被当成进步了 10 分。

这一节的半宽是**算出来的**，判分键里写死的那个数必须与脚本一致；`test_closed_book_template`
每次都会重算并比对。第一版写的「半宽约 ±8 分」是拍的，实算是它的两倍——**这种数不能靠感觉写**。

### 闸门线本身不可判：这不是「要点不够多」

上面那条说的是「三条带分不开」。背默卡那边还有一件**更根本**的事，2026-11-15 算清楚的：

**「S1 ≥ 0.8」这句话在任何要点数下都不是一个可判的判决。** 原因不是要点少，是算术：
相邻两档只差 `1/n`，而区间宽度是 `O(1/√n)`——`1/n` 衰减得更快，所以重叠会缩小，但**永远
不归零**。实测「不过线」与「过线」两档的区间重叠：18 点 **0.277**、60 点 **0.183**、
400 点 **0.071**（`npm run gate:check --table` 复现）。

所以：

- **闸门只做粗分**：S1 = 0.4 与 0.9 分得开；**贴线那一档永远不下判决**。
- **报分一律带区间**。读的人看见 `0.778（95% 区间 0.556–0.944）`，自然知道它不能当「没过关」。
- **想让闸门在某个点真的可判，唯一办法是让闸门线落在格点上**——15 条要点时要 12 条命中
  （12/15 = 0.8），20 条时要 16 条。**要点数选成让 `n × 闸门线` 是整数**，比「多加几条」有用。
- 真要判「过/不过」，改用「**区间是否完全落在闸门线一侧**」——更严，会把大量答卷判成
  「不可判」，但那才是诚实的。

**这一节与上面那条是两件事，别混**：上面说「三条带之间分不开」（间距不够），这里说
「一条闸门线左右分不开」（格点没对上）。两条都指向同一个结论：**报区间，不报判决。**

### 背默卡：与卷子并列的第二件产物

**卷子考「读懂了没有」，背默卡收「合上原文之后还能写出什么」。两件事不同，不要混。**

- **什么时候用**：学生要验「我到底记住了多少」，或者他自己说「我背一遍试试」。**它比卷子更接近
  真实场景**——课堂上没人给选项。
- **形状**：照 `<root>/templates/closed-book/背默卡.md`（空白卡 + 要点表 + 三轮填写：骨架 / 因果 /
  术语数值）。
- **要点表由出卷人先填**：**15–20 条**命题级要点（**8 条不够**，见下一条的分辨率），各标 `骨架` / `因果` / `术语`。**没有要点表就没有
  S1**——只能给印象分，而印象分的信度在 .30–.50 量级。
- **计分在判分键的「背默卡的计分」那一节**：S1 命题召回 + S2 结构档（0–3）+ 迁移探针，三条闸门
  缺一不算通过。**「字面搬运」判 S2 = 0**——抄原文能拿满 S1，但过不了结构档。
- **必须带区间报**。10 条要点、S1 = 0.80 时，要点的 bootstrap 半宽是 **0.25**——0.8 这条闸门线
  根本分辨不了 0.65 与 0.95。所以：**要点至少 15 条**（半宽降到 0.20），报分报
  「S1 = 0.80（95% 区间 0.55–1.00）」。`scripts/tools/recite-score.mjs` 一并给出来。
- **与卷子的分不可混算、不可相加**。要报就分开报。

### 报分用那份骨架：`templates/closed-book/检验记录.md`

上面这些规矩（带区间、三条局限、判定带只是报告用语、剖面比总分稳、拿不准的题要写出来）
**散在七八处，之前没有一份成品把它们一次落全**。学生答完题最可能发生的事，就是评分者只报
一个总分——而那个总分的半宽是 6–19 分。

**所以判完分要填那份骨架，不是随口报一句。** 它要求八件：
1. 谁、什么时候、**判分键是什么时候打开的**（选「之前」= 这次分数作废）；
2. 卷子五部分与总分、判定带；
3. 背默卡的 S1（**带 95% 区间**）、S2、探针、要点条数；
4. **三条必填局限，一条都不许省**；
5. **哪一部分最弱**（剖面比总分稳得多）；
6. **这次判得最没把握的一题**——**这一栏不许空着**，空着比判错一题更糟；
7. 锚点查了没有；
8. 放哪儿：**学生的原始作答不收进仓库**，记录里可以引原话，但不整篇附上。

填完的实例：

```
| 部分 | 得分 | 满分 |
| 一、骨架 | 14 | 20 |
| 二、因果 | 29.5 | 35 |
| 三、数值 | 20 | 20 |
| 四、迁移 | 14 | 15 |
| 五、元认知 | 10 | 10 |
| **总分** | **87.5** | **100** |

本次落在：**部分通过** 一带
```

**注意上面这个示例报的是「落在『部分通过』一带」，不是「没通过」。**

### 报分必须带上局限

一次性施测分不出「这次没想起来」与「本来就没学会」；一份卷子的分数区间半宽约 ±8 分（按 20 个
计分点估），差 8 分以内不要当真实差异；卷子按课件出，可能漏掉课件里有价值但没出题的部分。**这三条
写进判分键的末尾，报分时一起说。**
