# 背默卡 · <节点标题>

> **这是一张空白卡，不是卷子。** 卷子考「读懂了没有」，这张卡收「合上原文之后，你还能写出什么」。
> 两件事不同：卷子有题、有选项、有提示；这张卡**只有横线**。
>
> 照抄时把 `<课程名>`、`<节点标题>`、`<课件文件名>` 换掉。**「要点表」那一节由出卷人先填好**
> ——它是评分的尺子，不能让学生自己划。

## 怎么用（学生看的）

1. **先读**：把 `<课件文件名>` 读两三遍。读的时候**不要写这张卡**，也不要抄笔记。
2. **合上原文**：浏览器切走、文件关掉。**这一步是整件事的关键**——不闭卷，这张卡测的就不是提取。
3. **写三轮**（每轮 5–8 分钟，写不出来就留空，**不要编**）：
   - **第一轮 · 骨架**：这节课分成哪几块？每块一句话。**先写块名，再补内容。**
   - **第二轮 · 因果**：每一块里「因为什么，所以什么」。写不出的留 `?`。
   - **第三轮 · 数值与术语**：记得住的数与名词，写在最后。
4. **对着缺口重读**：只看你在卡上留了 `?` 或空着的地方，其余不重读。
5. **再默一次**（可选，但这一步才是真正长记忆的地方）：合上原文，把第一轮再写一遍。

**允许留白。** 留白比编一个像样的答案有用得多——编的答案会把评分带偏，留白不会。

## 要点表（**出卷人先填好，学生不要看这一节**）

> 这一节是评分的尺子。**先由出卷人从课件里抽出 8–15 条命题级要点**，标三类：
> `骨架` / `因果` / `术语`。学生交卡之后，评分者逐条对照「命中 / 部分 / 未中」。
>
> 为什么要有这张表：**没有预设要点，评分就只能给印象分。** 而印象分的信度在 .30–.50
> 量级（命题计分能到 95% 以上一致）。

| # | 类型 | 要点（一条一句话，可独立判真假） |
| --- | --- | --- |
| P1 | 骨架 | |
| P2 | 骨架 | |
| P3 | 因果 | |
| P4 | 因果 | |
| P5 | 因果 | |
| P6 | 因果 | |
| P7 | 术语 | |
| P8 | 术语 | |
| P9 | 术语 | |
| P10 | 术语 | |

**这张表的规模**：8–15 条。少于 8 条，评分太粗；多于 15 条，一轮 5–8 分钟写不完。

⚠️ **但实测推翻了「8 条就够」这个下限**：10 条要点、S1 = 0.80 时，要点的 bootstrap 半宽是
**0.25**——0.8 这条闸门线完全分辨不了。要让它有意义，**要点至少要 15 条**（半宽降到 0.20），
最好 20 条（0.175）。详见判分键的「S1 这条闸门线的分辨率」。

## 评分（判分键在另一份文件）

**这一张卡不自己判分。** 计分规则、闸门与区间在 `<NNNN>-<节点id>-判分键.md` 的「背默卡计分」一节；
本文件只负责**收集**。

两件事必须说清：

1. **被试必须是人。** 模型不代写这张卡——课件全文在它的上下文里，「合上原文」对它不构成约束。
2. **这张卡与卷子是两件事，不要混。** 卷子问「你能不能答对这道题」，卡问「你能不能不靠题、
   自己把学过的东西写出来」。后者更接近真实场景（课堂上没人给你选项）。
