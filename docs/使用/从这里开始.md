## 四、做完会得到什么

一份 `<NNNN>-<节点id>-检验记录-<日期>.md`，里面有：

- **五部分得分**与**判定带**（写「落在某一带」，不写「没通过」）；
- 背默的 **S1 与它的 95% 区间**（如 `0.75（0.583–0.917）`）；
- **哪一部分最弱**——这一项比总分有用；
- **三条必填局限**（一条都不会省）。

**你会看到的总分半宽是 6–19 分。** 意思是：**差 19 分以内不要当成真实差异**。
这不是这套东西做得糙，是 20 个计分点的卷子天然就这么粗——要把半宽压到 5 分，
计分点得到两百多个，30 分钟的卷子做不到。

## 五、这套系统**故意不做**的四件事

| 不做 | 为什么 |
| --- | --- |
| **不做复习排期** | 没有「到期」字段、没有待办、不会提醒你。节拍写在卷子里是**建议**（`docs/设计/目标态规格.md` §12 把间隔重复列为非目标） |
| **不替你读、不替你写、不替你判** | 模型不会忘——它做这件事测的是"改写"不是"提取"。**这条是这套方法的根** |
| **不给"建议掌握度"、不自动置位** | 考砸了那个节点仍然是「已学完」——「已学完」只表示读完了 |
| **不拿可读性公式当验收** | 有实证反例：词汇简化让感知难度降、但 Cloze 成绩反而变差（Leroy 2013, p=.004） |
