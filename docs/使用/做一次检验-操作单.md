# 做一次检验：操作单

> **这份是照着做的单子，不是说明。** 做完一次检验要动的文件、要跑的命令、要人做的判断，
> 按顺序列在这里。想先弄清"为什么这么做"，看 [使用说明 §六](使用说明.md)。
>
> 全程只有**两处必须人做**，其余都可以由模型代跑：**读并手写**、**判分**。

---

## 零、先跑一遍总检查（1 分钟）

```bash
npm run methods:check
```

它查的是「产物干不干净」——卷子与判分键成对、配分算术自洽、要点表够数、题目材料课件里有、
答案没落进可读目录。**不通过就先别开始检验**，修完再跑。

---

## 一、准备（模型做，5 分钟）

| 步 | 做什么 | 产出在哪 |
| --- | --- | --- |
| 1 | 出**卷子**与**判分键**（两份同时写、同时落盘） | `<subject_path>/assessments/<NNNN>-<节点id>-{卷子,判分键}.md` |
| 2 | 要做背默就再出**背默卡**，**并把第 4 节点要表填满** | `…-背默卡.md` |
| 3 | 从要点表生成**空白判分表** | `npm run recite:sheet -- <背默卡.md> --out 判分表.md` |

**判分键不许进 `reference/`。** 那是学生随手能点开的地方——`npm run methods:check` 会拦住。

---

## 二、读（**人做**，20–40 分钟）

**顺序很重要，而且和直觉相反：**

| 步 | 做什么 | 为什么 |
| --- | --- | --- |
| 1 | **读一遍**课件。不停顿、不划线、不抄笔记。 | 第 1 遍只要建立骨架 |
| 2 | **合上原文，立刻写第一轮**：这节课分成哪几块，每块一句话。5–8 分钟。 | 这一轮在有缺口的状态下写，是有效的 |
| 3 | **带缺口重读**：只回头读你留了 `?` 或空着的地方，**其余不重读**。 | 3R 的 review 环节 |
| 4 | **合上原文，写第二轮与第三轮**：因果（每块「因为…所以…」）+ 术语数值。**这一轮才计分。** | 第二次检索才是有间隔的那次 |

**两次都要闭卷。** 第二次看着第一轮的答案写，测的就不是提取了。

**写不出来就留空，不要编。** 编的答案会把评分带偏，留白不会。

---

## 三、判分（**人做**，15–25 分钟）

**判分键现在才打开。** 打开之前先在这一行签字：

> 我是在收到作答之后才打开判分键的：☐

### 卷子

按判分键逐题给分。每个得分点只判一件事；值差在 ±2% 内算命中；
「答得比课件更深」不扣分（若该卷有此口径）。

### 背默卡

```bash
# 1. 在 判分表.md 里逐行勾：命中 / 部分 / 未中 三选一
# 2. 填末尾的 S2 结构档（0–3）与迁移探针（0/1）
# 3. 算：
npm run recite:table -- 判分表.md --s2 <0-3> --probe <0|1>
```

它会印出可以直接抄进报分单的一行：

```
S1 命题召回 = 0.75（95% 区间 0.583–0.917）
```

**若它印的是「闸门 0.8 落在区间内 —— 这一次判不出「过/不过」」，就照这个写。**
不许自己改成「不通过」——那一刻本来就判不出来。

**若它印的是「一条都还没判」**，说明表还没勾，回去勾。

---

## 四、报分（模型做，5 分钟）

照 `templates/closed-book/检验记录.md` 填，**三条必填局限一条都不许省**：

1. 一次性施测，分不出「没想起来」与「没学会」；
2. **卷子半宽 6–19 分**（差 19 分以内不算真实差异）；背默 S1 半宽 0.19–0.20；
3. 产物是按课件出的，可能漏了有价值但没出题的部分。

外加三件必须写：
- **哪一部分最弱**（剖面比总分稳）；
- **这次判得最没把握的一题**（**不许空着**——空着比判错一题更糟）；
- **本次落在哪一带**——写「落在『部分通过』一带」，**不写「没通过」**。

---

## 五、存档（模型做）

| 放什么 | 放哪 |
| --- | --- |
| 检验记录 | `assessments/<NNNN>-<节点id>-检验记录-<日期>.md` |
| **学生的原始作答** | **不收进仓库、也不收进 `assessments/`**——那是学生自己的东西 |

记录里可以引作答原话，但不整篇附上。

---

## 六、什么时候再做一次

卷子里有那一节。摘要：

| 你要记多久 | 重做时点 |
| --- | --- |
| 一周内要用 | **+1 天** |
| 一个月内要用（默认） | +1 天、**+11 天**、+30 天 |
| 跨学期 | +1、+21、+110 天 |

**不是日程，系统不会提醒你。** 什么时候做，你自己定。

**答对了也别停**——答对即停的组一周后剩 35%，继续检索的剩约 80%。

---

## 只有两件事这个系统不做

1. **不做复习排期。** 没有「到期」字段、没有待办列表、不会来提醒。这是有意的
   （`docs/设计/目标态规格.md` §12 把间隔重复列为非目标）。
2. **不替你读、不替你写、不替你判。** 模型不会忘——它做这件事测的是"改写"不是"提取"。
